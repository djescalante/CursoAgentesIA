# Reglas de Contenido del Curso (Markdown)

1. **Tono y Estilo**:
   - El tono debe ser didáctico, entusiasta y técnico pero accesible.
   - Dirígete al lector de "tú".
   - Usa emojis moderadamente para destacar secciones (ej. 🛠️ para Prácticas, 💡 para Tips).

2. **Estructura de un Módulo**:
   - Título principal (`#`) con el nombre del módulo.
   - Breve introducción.
   - Subsecciones (`##` y `###`) lógicas.
   - Bloques de código siempre con el lenguaje especificado (ej. ` ```bash `, ` ```json `).
   - Referencias a metodologías (como SDD) deben explicarse brevemente si son introducidas por primera vez.

3. **Restricciones**:
   - No usar HTML embebido en los `.md` teóricos salvo estricta necesidad.
   - Los enlaces a otros módulos deben ser relativos (ej. `[Módulo 1](../modulo-1/...)`).
