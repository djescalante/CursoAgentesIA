# 🐳 Curso de Docker y Docker Desktop (2026)

Bienvenido al curso interactivo de Docker y Docker Desktop. Este curso está diseñado para llevarte desde los fundamentos de la contenerización hasta el despliegue de arquitecturas multi-contenedor en la versión más reciente.

## 🚀 Cómo Empezar
1. Lee la [Guía de Inicio Rápido](QUICK_START.md) (30 min).
2. Sigue las instrucciones en [Instalación](INSTALLATION.md).
3. Revisa el [Manifiesto del Curso](MANIFEST.md) para ver todo el temario.

## 📁 Estructura del Curso
- **Módulos 1-4**: Fundamentos, Imágenes, Volúmenes y Redes.
- **Módulos 5-7**: Compose, Optimización, Casos Reales y Proyecto Final.
- **Recursos**: Cheatsheets, plantillas y ejemplos funcionales listos para usar.
