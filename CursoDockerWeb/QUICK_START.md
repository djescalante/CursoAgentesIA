# ⚡ Inicio Rápido (30 Minutos)

Esta guía rápida te enseñará a correr tu primer contenedor en Docker Desktop 2026.

## 1. Requisitos
- Docker Desktop instalado (Ver INSTALLATION.md).

## 2. Tu primer comando
Ejecuta en tu terminal:
`ash
docker run -d -p 80:80 nginx:latest
`
Abre tu navegador en http://localhost. ¡Felicidades! Tienes tu primer contenedor corriendo.
